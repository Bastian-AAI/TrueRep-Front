# TrueRep-Front

Módulo frontend en Flask para **TrueRep**, Analizador Biomecánico y Contador de Repeticiones para **Sentadilla (Squat)** y **Flexiones (Push-up)**.

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
python main.py
```

Disponible en `http://127.0.0.1:7001/ejercicio2/app2-front/`.
